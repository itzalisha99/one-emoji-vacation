A make.fun bounty entry. The program writes exactly one emoji to `/output/entry.txt`: a thatched hut 🛖 — the faraway stay itself. One little hut on a distant shore, yours for the week, nothing else on the agenda.

## The emoji

> 🛖

One character, four bytes, no words, no extra characters. A self-authored `validate()` gate mirrors the bounty gate before writing: UTF-8 text, 1 to 8 characters, not only whitespace, exactly one emoji.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
